-Alien Fishing (title not final)-

This is a project started out of the blue to build up experience in the Unity Engine and make a game of quality that im happy with.

Is a cozy fishing style game where you play as an alien documenting all the odd things you manage to scrounge up from the earth in an attempt to find anything to help fix your flying saucer that's falling apart.

Development currently should last around 2-3 months before being published to itch.io.
